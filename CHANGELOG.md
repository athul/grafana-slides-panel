# Changelog

## 1.5.1

First public release.

- Render a PDF deck in a panel with pdf.js, full-window in kiosk mode
- Keyboard and clicker navigation, jump to slide, blank screen, fullscreen
- Presenter view with next slide, speaker notes, timer and clock, synced across windows
- Clickable PDF links; same-origin dashboard and panel links shown live on the slide
- A link to the deck's own dashboard shows the deck inside Grafana's full UI
- Fade transitions, progress bar and slide counter
